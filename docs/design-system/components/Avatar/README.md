# Avatar

A `avatar-size` disc with the account's initials over the `avatar-top`→`avatar-bottom` gradient and an `avatar-ring` border.

Initials use `type-initials`, the first letters of the first two words. A keyboard-focused avatar in an account row gets the `focus-ring`. Account photos, when supported, replace the gradient and initials but keep the size and ring.

**Provide.** The display name, and whether it has keyboard focus.
