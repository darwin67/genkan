# Brand

Genkan's icon, [`assets/icon/genkan.svg`](../../../../assets/icon/genkan.svg): a shoji door slid partway open with light from inside. The card shows its clear space, a quarter of the icon's width on every side, and the single SVG at 128, 64, 32, 24 and 16 px on a dark background.

The icon identifies the project in the README, the repository card and the catalogue Cover. It never appears on the login or lock screen. Colors, clear space, how to set the name beside it, and the social preview are in [Brand](../../README.md#brand).
