= RFD 0007 implementation checklist

Implements link:README.adoc[RFD 7: Account pictures].

== Phase 1: Built-in pictures

* [x] Add the twelve approved SVG sources to `assets/avatars/`.
* [x] Render them to 512 by 512 PNGs with the pinned resvg
  (`make update-avatars`), commit them, and install sources and PNGs under
  `share/genkan/avatars/`.
* [x] Pin every source and output by SHA-256 in a manifest checked by the
  build, and reject text, scripts, styles and external references in the
  sources (`scripts/check-avatars.py`).

== Phase 2: Sandboxed decoder

* [x] Add the hidden `genkan avatar-decode` process: no-new-privileges,
  resource limits, seccomp filter, PNG and JPEG only, dimension limit, centered
  square crop, 256 by 256 premultiplied RGBA output. JPEG uses zune-jpeg, which
  decodes on one thread; the `image` crate's JPEG decoder starts worker threads,
  which the filter forbids.
* [x] Add the parent side: safe open, empty environment, exact-length read,
  two-second timeout, kill and reap (`genkan::avatar::decode_file`).
* [x] Test malformed, oversized, truncated, slow and non-image inputs, and the
  sandbox the kernel reports for a running decoder (`tests/avatar_decode.rs`).
  Falling back to initials is Phase 3.

== Phase 3: Showing pictures

* [x] Read `IconFile` with the other AccountsService properties.
* [x] Draw decoded pictures in the login avatar and account tiles, loading
  after the accounts appear and decoding each file once per run. The
  `account-pictures` preview fixture shows built-in pictures through the real
  decoder beside an account that keeps its initials.
* [x] Draw the locked user's picture in the lock's CPU renderer: looked up
  through AccountsService `FindUserById` and decoded on a background thread,
  so locking never waits for it. The `account-picture` lock preview fixture
  shows it.

== Phase 4: Choosing pictures

* [x] Add `genkan avatar list`, `set <name>`, `set --file <path>` and `clear`.
* [x] Re-encode photos as metadata-free 512 by 512 PNGs before `SetIconFile`.
* [x] Extend the greetd VM test: set a picture as the user, see it on the login
  screen, and see initials for a malformed file.

== Phase 5: Records

* [ ] Update RFD 1, RFD 5 and the design system's Avatar component.
* [x] Document `genkan avatar` in the deployment guide.
